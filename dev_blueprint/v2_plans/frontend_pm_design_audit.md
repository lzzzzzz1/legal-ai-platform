## 一、 当前前端设计现状与用户心智模型 (User Mental Model)

在合同审查场景中，用户的核心工作流程是**“阅读合同 → 发现问题 → 修改确认 → 导出定稿”**。用户的心智模型要求：**极高比例的文档阅读区、极具确定性的修改对比、无打扰的流式操作**。

## 二、 核心痛点与不合理性审计 (Auditing the Painpoints)

### 痛点 1: 上传表单强占黄金视觉区域 (Header Space Congestion)
*   **不合理表现**：左侧主阅读器面板 (`.reader-panel`) 的最顶部放置了巨大的虚线拖拽上传区 (`.file-drop`)，即使在上传并审查完成后，这块非核心区域依然常驻在正文编辑器的上方。
*   **用户影响**：黄金视觉高度（首屏上半部）被“已载入合同”等静态无用状态长期霸占，导致核心编辑器区域被迫推挤到屏幕下方，用户必须向下滚动才能看全合同，严重挤压了阅读合同的视线。

### 痛点 2: 缺乏“审阅对比模式”，修改透明度低 (Opacity of Edits)
*   **不合理表现**：用户点击右侧“引用修改”后，正文编辑器直接执行静默字符替换（原字词消失，新字词出现），仅在上方弹出简短的通知。
*   **用户影响**：法务对字词极其敏感。直接“吃掉原文”会让法务产生“失去控制”的焦虑感，他们无法直观比对出“AI到底删了哪些字，添了哪些字”，必须靠人脑记忆去前后比对。

### 痛点 3: 双栏布局固定，在中小屏设备被极度挤压 (Brittle Two-Column Width)
*   **不合理表现**：双栏比例固定为 `1.45fr` 比 `0.9fr`，右侧审查栏最小宽度限制在 `360px`。
*   **用户影响**：法务和律师经常出差，使用的是 13-14 寸轻薄本。在此类小屏幕下，核心合同正文区域被极度压缩，一行只能显示十几个字，导致阅读体验极差。

### 痛点 4: 风险卡片缺乏“状态流转”与过滤器 (Lack of Card Status Filter)
*   **不合理表现**：点击“引用修改”或“追加条款”后，右侧卡片除了隐藏或追加统计数据，没有显性的状态切换，也无法隐藏已解决项。
*   **用户影响**：对于包含几十个风险点的长合同，用户滑动长列表时分不清哪些看过了、哪些接受了、哪些忽略了。缺乏“进度控制”导致审阅效率低下。

## 三、 PM 视角下的前端 UI/UX 优化方案

为了将这个“研发原型”提升为“高产出法务工作台”，建议从以下五个方向进行前端界面重构：

```
+-------------------------------------------------------------------------+
| [LA Brand]  | [合同类型: 采购合同 V]                [已修订: 2/4] [导出 Word] |  <-- 1. 顶栏扁平流
+-------------------------------------------------------------------------+
|                  |                                                      |
|   [ 📝 合同正文]  |                [ ⚠️ 风险项审查清单 ]                 |
|   双方于...      |                                                      |
|   ~~上海~~       |  [高风险] 签订地点缺失  [定位] [已解决]              |
|   **北京** 签署。|  --------------------------------------------------  |  <-- 2. 局部痕迹对比
|                  |  [中风险] 税务调整条款  [定位] [接受修改]            |  <-- 3. 状态一键过滤器
|                  |                                                      |
|                  |                                                      |
+-------------------------------------------------------------------------+
|   [<- 拖动分栏 ->]                                                       | <-- 4. 宽度可自由拖拽
+-------------------------------------------------------------------------+
```

### 1. 黄金阅读区归还：收起/折叠上传卡片
*   **改进设计**：一旦合同审查成功，`.file-drop` 虚线框应**自动滑动收起/折叠**。
*   **原型构想**：将已载入文件名、大小等元信息，以极其扁平的 **Meta Bar** 常驻在编辑器最顶层，右侧保留微型“重新上传”文字链。原虚线大框全部转化为编辑器的显示空间。

### 2. 深度可视：新增“局部对比痕迹”与“撤销”按钮
*   **改进设计**：当引用修改时，利用 Tiptap 渲染出删除线与高亮新词。
*   **卡片级互动**：点击引用后，右侧风险卡片的“引用修改”按钮变更为“**撤销修改**”，点击可一键将左侧对应的文本还原。这给予了法务 100% 的修改自主权与控制感。

### 3. 工作流精细化：卡片状态切换与“已修订”过滤
*   **改进设计**：
    *   卡片状态分为：`未处理`、`已接受`、`已忽略`。
    *   当点击“引用”后，卡片自动进入 `已接受` 状态，卡片背景微变暗淡并盖上绿色“已修订”微章。
    *   在风险列表头部，新增单选按钮（Filter Tabs）：“全部风险 ({all})” / “未处理 ({todo})” / “已处理 ({done})”。

### 4. 弹性响应式：支持双栏宽度拖拽调节 (Resizable Split Layout)
*   **改进设计**：
    *   在左侧阅读区与右侧工具栏之间，添加一根半透明的可拖拽分割线。
    *   用户可以自由拖动分割线以放大/缩小合同正文区。
    *   右侧面板支持“一键收起（Collapse）”按钮，收起时仅保留气泡红点数量，把 100% 宽度留给左侧正文，实现极简专注阅读。

### 5. 焦点聚焦：增强“定位原文”的视觉脉冲
*   **改进设计**：当用户点击卡片上的“定位正文”时，左侧编辑器被选中的行或段落除了加上背景色，还要附加一个持续 1 秒的 **闪烁阴影脉冲动画 (Pulse CSS Animation)**。这样在长文档中，用户能瞬间捕捉到视线焦点，不用四处搜寻。
