# Legal AI V2.0 手动验收清单

## 一、浏览器端验收

### 1. 企业合同类型识别
- 上传一份采购/供应合同，确认右侧显示 `采购/供应合同`
- 上传一份服务合同，确认右侧显示 `销售/服务合同`
- 上传一份 NDA，确认右侧显示 `保密协议`
- 上传一份普通商业协议，确认右侧显示 `通用商务合同`

### 2. 风险定位与引用
- 点击右侧“定位正文”，确认正文滚动到目标段落并高亮
- 点击正文段落，确认右侧自动聚焦到最相关风险卡
- 点击“引用修改”，确认正文出现：
  - 红线删除旧词
  - 绿底高亮新词

### 3. 缺失条款插入
- 对缺失条款点击“追加条款”
- 若自动定位失败，点击正文任意段落，确认出现橙色插入目标高亮
- 点击“插入到该段后”，确认新增条款以绿色插入样式显示

### 4. 本地占位符检查
- 在合同正文中确认存在 `【...】` 的建议文本
- 占位符应显示为黄底/虚线提示样式

### 5. 布局体验
- 审查完成后，上传大卡片应收拢为紧凑状态栏
- 点击右侧栏折叠按钮，确认：
  - 风险侧栏完全隐藏
  - 编辑器进入居中 800px 聚焦模式
- 再次点击，确认侧栏恢复

## 二、导出文件验收（WPS / Microsoft Word）

### 1. 导出修订痕迹
- 在浏览器中点击“确认并导出修改版”
- 使用 WPS 或 Microsoft Word 打开导出的 `.docx`
- 确认文档处于“修订/审阅”可见状态

### 2. 替换类修订
- 被替换的原文应显示为删除痕迹
- 新建议应显示为插入痕迹
- 修订作者应为 `Legal AI`

### 3. 缺失条款追加
- 新增条款应显示为插入修订，而不是普通静态文本
- 插入位置应位于选定锚点段落之后

### 4. 样式完整性
- 原段落编号、列表、表格不应明显损坏
- 新增段落应尽量继承周边段落样式
- 文档打开时不应报“文件损坏”或“修复内容”

## 三、回归建议样本

建议至少手动验证以下 4 份样本：
- 采购/供应合同（中文）
- 服务合同（中文）
- NDA（英文）
- 带编号条款与 `Counterparts / Notices / Taxes` 标题的英文商业合同
